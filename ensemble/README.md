# ensemble/ — the 80/20 validated pipeline (local val ADE 2.758)

The honest cross-validation pipeline: the 6 members are trained on **80 %** of the data
(`train_files.txt`) and the 2-group **ball | players** ensemble weights are fit on the held-out
**20 %** (`val_files.txt`), then applied to the test predictions. This is what gives a trustworthy
local number; the final Kaggle submission (`../final/`) reuses these same weights on members
retrained on 100 % of the data.

## The 6 members

Single architecture (`NBAv46Model`), trained six ways:

- **Ball specialists** (ball-weighted NLL): `v60_w8`, `v60_w5_s1`, `v60_w8_s2`
- **Player generalists** (standard NLL, different seeds): `v46`, `v46_s3`, `v46_s7`

## What's here

```
models/      The 6 members' definitions (nba_v46 + 2 seed copies + nba_v60 ball-weighted
             trainers). Copies of the demarche/ originals so this folder is self-contained.
weights/     The 6 member checkpoints (model_<label>_300ep.pth), trained on the 80% split.
solutions/   solution_ball_player_2grp.csv  (the validated 2-group submission).
_config.py   All paths + the NML_DATA data location (single source of truth).
```

## The method

The score averages MSE uniformly over 11 entities, but the **ball alone is ~39 % of the total
error** (≈6× any player — it is passed and shot, not smoothly moving). See
`analyze_error_sources.py`.

So instead of one global weight vector we fit **two**: one for the ball (entity 0), one shared
across the 10 players. The optimiser then routes the **ball-weighted models** to the ball and the
**accurate generalists** to the players — a partition predicted by the error analysis.
`ball_player_ensemble.py` performs that fit; `show_weights.py` prints the fitted vectors.

## Reproduce

```bash
export NML_DATA=/path/to/nml-2026
python core/make_split.py                  # regenerate train/val manifests for this machine

# The 6 member weights are committed. (To rebuild one: train it with
# `python core/run_one.py ensemble/models/<file>.py 300 32`.)

python ensemble/save_val_tta_preds.py      # GPU: cache per-model val predictions  -> val_preds/
python ensemble/save_test_tta_preds.py     # GPU: cache per-model test predictions -> test_preds/
python ensemble/ball_player_ensemble.py    # CPU: fit 2-group weights, write solution_ball_player_2grp.csv
python ensemble/show_weights.py            # CPU: print the fitted ball | player weight vectors
```

`val_preds/` and `test_preds/` are gitignored caches — regenerated by the two `save_*` scripts.
