# ensemble/ — the 80/20 validated pipeline (Kaggle 2.98086)

Members trained on **80 %** of the data (`train_files.txt`), validated on the held-out **20 %**
(`val_files.txt`). The 2-group **ball | players** ensemble weights are fit on that honest val split,
then applied to the test predictions → [`solutions/solution_ball_player_2grp.csv`](solutions/solution_ball_player_2grp.csv).

## What's here

```
models/      The graph model definitions (nba_v46 + 8 seeds, nba_v58 + 3 seeds, nba_v60 ball-
             weighted variants). nba_v46.py / nba_v58.py are copies of the demarche/ originals,
             kept here so this folder is self-contained at inference time.
weights/     The 27 member checkpoints in the 2.98 pool (see POOL in ball_player_ensemble.py).
solutions/   solution_ball_player_2grp.csv  (the 2.98086 submission).
_config.py   All paths + the NML_DATA data location (single source of truth).
```

## The method

The score averages MSE uniformly over 11 entities, but the **ball alone is ~39 % of the total
error** (≈6.3× any player — it is passed and shot, not smoothly moving). See
`analyze_error_sources.py` and [`../docs/ERROR_ANALYSIS.md`](../docs/ERROR_ANALYSIS.md).

So instead of one global weight vector we fit **two**: one for the ball (entity 0), one shared
across the 10 players. The optimiser then routes the **ball-weighted models** to the ball and the
**accurate generalists** to the players — a partition predicted by the error analysis.
`ball_player_ensemble.py` is the winning fit; `weighted_ensemble*.py` are the full per-entity /
single-vector variants we compared against.

## Reproduce (2.98086)

```bash
export NML_DATA=/path/to/nml-2026
python core/make_split.py                  # regenerate train/val manifests for this machine

# Weights for all 27 members are committed. (To rebuild them: train each member with
# `python core/run_one.py ensemble/models/<file>.py 300 32`, then `python ensemble/make_all_swa.py`.)

python ensemble/save_val_tta_preds.py      # GPU: cache per-model val predictions  -> val_preds/
python ensemble/save_test_tta_preds.py     # GPU: cache per-model test predictions -> test_preds/
python ensemble/ball_player_ensemble.py    # CPU: fit 2-group weights, write solution_ball_player_2grp.csv
```

`val_preds/` and `test_preds/` are gitignored caches — regenerated by the two `save_*` scripts.
Inspect the fitted weights any time with `python ensemble/show_weights.py`.
